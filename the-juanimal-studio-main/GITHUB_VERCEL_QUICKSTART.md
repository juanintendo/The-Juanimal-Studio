# GitHub + Vercel — Quick Start (Next.js)

## 1. Push to GitHub

```bash
git remote add origin https://github.com/YOUR_USER/juanimal-studio.git
git branch -M main
git push -u origin main
```

## 2. Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) → **Add New → Project**
2. Import `juanimal-studio`
3. Framework Preset: **Next.js** (auto)
4. **Deploy**

Typical URL: `https://juanimal-studio.vercel.app`

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
